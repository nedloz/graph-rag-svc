# Зависимости провайдера LLM_PROVIDER=local — ТОЛЬКО для локальной разработки.
#
# Зачем отдельный файл: `local` — единственный backend, который грузит модель в процесс
# самого сервиса, а не в отдельный контейнер, и в прод-среде использоваться не должен
# (см. app/generation/llm_backends.py::_stream_local_transformers). При этом раньше эти
# пакеты ставились в образ всегда: около 5 ГБ колёс nvidia-* ради кода, который при
# LLM_PROVIDER=stub/ollama/openai не выполняется ни разу. Импорты в коде ленивые —
# внутри функций провайдера, — поэтому без этих пакетов остальной сервис работает как есть.
#
# Как поставить:
#   docker compose build --build-arg WITH_LOCAL_LLM=true graph-rag-svc
# или GRAPH_RAG_WITH_LOCAL_LLM=true в main/.env — тогда обычный `docker compose build`
# соберёт образ с ними.
#
# torch запинен той же версией, что и в embedding-svc: там он используется по-настоящему,
# и эта пара «версия + индекс» в проекте уже проверена. Раньше здесь стояло `torch>=2.2.0`,
# что разрешалось в свежайшую сборку с CUDA 13 — другой набор nvidia-* колёс и другой объём
# при каждой пересборке. Для машины без GPU замените индекс на .../whl/cpu.
--extra-index-url https://download.pytorch.org/whl/cu126

torch==2.10.0+cu126

# transformers/accelerate оставлены нижними границами: они весят немного, а совместимость
# конкретных версий с torch тут не проверялась — жёсткий пин без проверки только мешал бы.
transformers>=4.48.0
accelerate>=0.26.0
